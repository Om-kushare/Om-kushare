# 🚚 Featured Project

## Goods Transport Network

A web-based **logistics management system** developed using Java and Spring MVC.

### 🎯 Objective

The main objective of this project is to allow customers to book vehicles according to their transportation requirements and help drivers manage delivery requests efficiently.

### 👥 Main Modules

**👨‍💼 Admin**

* Manage customers
* Manage drivers
* Manage vehicles
* Manage bookings

**🚚 Driver**

* Driver registration and login
* Vehicle registration
* View assigned transport requests
* Manage booking requests
* View booking history

**👤 Customer**

* Customer registration and login
* Book vehicles
* View booking details
* Track booking status

### 🛠️ Technologies

`Java` `Spring MVC` `Spring JDBC` `MySQL` `JSP` `HTML` `CSS` `Bootstrap` `JavaScript`
